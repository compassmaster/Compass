## 状態別・画面別手順

1. `npm run dev -- --host 0.0.0.0` を実行し、表示されたURLをブラウザで開く。
2. **ホーム**: データなしで初回利用ガイドが1列になること、進捗・説明・ボタンが切れないことを確認する。「地域・天気へ」で地域設定へ移動し、地域保存後に進捗が更新されることを確認する。今日のCompassとEvidence / Understanding / Formal UserModelのdetails、長い内部IDも確認する。
3. **記録**: 「日々の記録へ」「睡眠記録へ」が記録タブへ移動することを確認する。睡眠とDailyLogを作成・編集・削除し、入力、5段階ボタン、確認ダイアログが重ならないこと、保存後にガイド進捗が同期することを確認する。
4. **ふりかえり**: 空状態とデータあり状態で件数、日別カード、日時が幅内に収まることを確認する。
5. **関係**: 空状態とデータあり状態でカードが1列になり、使用記録detailsと長いEvidence参照を読めることを確認する。
6. **明日の見通し**: 空状態・データあり状態・取得エラー状態で比較情報、警告、ボタンが幅内に収まることを確認する。
7. **Compass Map**: Long-term / Short-term、空状態、警告、内部ID、Evidence参照を確認する。
8. **バックアップ**: exportボタン、file inputを操作する。有効なバックアップと不正ファイルを選び、件数プレビュー、警告・エラーが折り返すことを確認する。復元後にホームへ戻り、初回利用ガイドの進捗が復元データと同期することを確認する。
9. OSのライト/ダーク設定を切り替え、今回はライトUIのままinput/select/textareaだけが暗色化しないことを確認する。
10. 各NGは対象幅、タブ、データ状態、再現手順、スクリーンショットを記録する。
